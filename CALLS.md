# Проверка аудиозвонков

Первая версия поддерживает один личный аудиозвонок в открытом веб-клиенте.
Состояние звонка сохраняется при переходе между чатами. Видеозвонки, группы,
ожидающий второй вызов и вызовы при закрытом браузере в эту версию не входят.

## Настройка API и сайта

1. Finchat должен объявлять `hi.ctrl.params.calls.provider = "livekit"`.
   Если поля нет, клиент показывает причину недоступности и не создаёт звонки.
2. Backend Finchat должен выдавать LiveKit JWT и отправлять уведомления через `me`.
   Нужно настроить LiveKit, его webhook и доступность медиа, включая TURN.
   Секреты LiveKit остаются на backend Finchat, веб-клиенту они не нужны.
3. Сайт должен открываться через HTTPS (для локальной разработки допустим localhost).
4. В окружении `server.mjs` задайте `LIVEKIT_URL=wss://call.finchat.club`, если хост
   отличается от значения по умолчанию. Этот параметр разрешает адрес в CSP;
   адрес подключения и JWT клиент получает из ответа Finchat.
5. Если перед Node стоит reverse proxy, его CSP и Permissions-Policy тоже должны
   разрешать микрофон своего origin и подключения к LiveKit. Политику камеры
   менять не требуется: в этой версии она запрещена.
6. После изменений пересоберите сайт и перезапустите сервер:
   `npm run build`, затем `npm start`. Vite preview не проверяет production-заголовки
   из `server.mjs`.

## Проверка двумя пользователями

Потребуются два отдельных тестовых аккаунта с существующим личным чатом.
Используйте разные профили браузера или разные устройства. Две вкладки одного
профиля синхронизируют авторизацию и не подходят для входа разными пользователями.
Для проверки звука используйте наушники.

1. Войти обоими аккаунтами, разрешить микрофон, открыть личный чат и нажать «Позвонить».
2. Во втором браузере убедиться, что входящий виден даже при открытом другом чате.
   Нажать «Ответить», проверить звук в обе стороны и счётчик разговора.
3. Выключить и включить микрофон, перейти в другой чат во время разговора.
4. Завершить звонок с каждой стороны; индикатор захвата микрофона должен исчезнуть.
5. Проверить отклонение, отмену исходящего, отсутствие ответа и запрет микрофона.
6. Провести разговор дольше минуты: срок первоначального JWT не должен его прерывать.
7. Проверить короткую потерю сети. После восстановления Finchat сверяет состояние,
   LiveKit восстанавливает звук средствами SDK. Если SDK окончательно отключился,
   клиент завершает участие и предлагает позвонить снова.

Автоматические проверки сигналинга: `npm test`. Они не заменяют проверку настоящего
микрофона, сетевого доступа к LiveKit/TURN и разговора двух пользователей.
